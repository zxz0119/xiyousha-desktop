# 西游杀桌面版

Windows x64桌面卡牌游戏，支持3–12人单机对局与局域网真人／AI混合对局，提供39名人物、四种身份、卡牌查询、存档、对局记录和视频导出。

**v0.10.0安装包已验收，正在准备正式发布。** 当前公开安装包仍为0.9.0；本页展示的是0.10.0实际运行界面。

[下载已发布的v0.9.0](https://github.com/zxz0119/xiyousha-desktop/releases/download/v0.9.0/xiyousha_0.9.0_x64-setup.exe) · [所有版本](https://github.com/zxz0119/xiyousha-desktop/releases)

## 单人与联机

单人模式选择3–12人和简单、普通、困难AI，抽取身份后从三名候选人物中选择一名。起始四张手牌，正常回合依次处理回合开始与判定、摸牌、出牌、弃牌。

![v0.10.0单人牌桌](images/gameplay-v010.png)

联机模式支持同一局域网内创建房间、自动发现和IP直连。房主可配置人数、机器人、角色与卡牌禁用、响应时限；默认出牌时间120秒。支持公共聊天、私聊、掉线AI接管与原席位重连。

![v0.10.0联机牌桌](images/online-gameplay-v010.png)

## 身份与资料

唐僧和取经人共同击败妖怪、神仙，唐僧须存活；妖怪击败唐僧且仍有妖怪存活；神仙先击败妖怪，再击败唐僧且自己存活。其他身份默认隐藏，阵亡后公开；牌桌按公开信息显示剩余身份数量。

卡牌查询可以按牌库、人物、身份分类浏览，查看卡面、技能、花色和数量。对局记录支持回合查看，已结束对局可导出带音乐的视频；单人保留GM，联机禁用GM。

## 安装与更新

正式发布后下载Windows x64安装EXE，按向导完成安装。安装包约276.5 MiB，内置联机与视频编码运行资源，无需另装Node.js、Python或FFmpeg；窗口与视频渲染使用系统WebView2／Edge。安装前请保存并退出当前对局。

![v0.10.0安装向导](images/installer-v010.png)

已安装版本可在“游戏设置 → 版本与更新”检查新版本；更新包先验签，再由用户确认安装。只需下载 `.exe`，同名签名和 `latest.json` 用于自动更新。
